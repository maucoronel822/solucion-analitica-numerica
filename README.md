# Simulación de Crecimiento Poblacional

Este proyecto compara el **Método de Euler** (numérico) con la **Solución Analítica** de la ecuación diferencial:
dy/dt = 0.5y

### Parámetros:
- **Condición Inicial:** y(0) = 100
- **Paso de tiempo (h):** 0.2
- **Intervalo:** [0, 1]

### Conclusiones:
Al usar un paso de h=0.2, el método de Euler subestima ligeramente el crecimiento 
real debido a que la pendiente cambia constantemente en la función exponencial.
